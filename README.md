# ClaudePace — downloads

Know when your Claude limit runs out. Before it does.
A tiny macOS menu bar app that forecasts your Claude Pro/Max session and weekly limits.

**Website:** https://claudepace.com
**Download:** [latest release](https://github.com/Onemarsmedia/claudepace-releases/releases/latest/download/ClaudePace.zip)

Requires macOS 14+ and Claude Code signed in on the same Mac.
This repository only hosts release builds. ClaudePace is not affiliated with Anthropic.
